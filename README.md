# GraduateWork_E-book

**RU** · [EN](#english)

Документы дипломного проекта «**Электронная книга на базе ESP32**»: Белорусский государственный
университет информатики и радиоэлектроники (БГУИР), факультет компьютерных систем и сетей,
кафедра электронных вычислительных средств, 2022 год.

Прошивка устройства лежит в отдельном репозитории
[beanbo/E-book](https://github.com/beanbo/E-book).

## Что в репозитории

| Файл / папка | Что это |
|---|---|
| `ТЗ.docx` | задание на дипломный проект |
| `Пояснительная записка.docx` | пояснительная записка |
| `Титульный лист ДП 2022.docx` | титульный лист |
| `Перечень элементов.doc`, `Спецификация на СБ.doc` | перечень элементов и спецификация на сборочный чертёж |
| `Отзыв.docx` | отзыв |
| `Чертежи/*.pdf` | чертежи и схемы в PDF: принципиальная, структурная, алгоритм, плата, сборочный чертёж, плакат |
| `Чертежи/исходники/` | исходники: схемы Altium Designer (`.schdoc`, `.SchLib`), чертежи AutoCAD (`.dwg`, `.DXF`) |
| `full_functional_scheme.drawio`, `plakat.drawio` | функциональная схема и плакат в draw.io |

## Как открыть

Это документы, а не программа: собирать нечего. Нужны Microsoft Word (или LibreOffice), любой
просмотрщик PDF, draw.io (diagrams.net); для исходников чертежей — Altium Designer и AutoCAD.

## История

Работа велась с апреля по июнь 2022 года: коммиты от первых файлов (15.04.2022) через
нормоконтроль (май) до «Финальный диплом» (08.06.2022).

## English

Documents of the graduation project **"E-book based on ESP32"** — Belarusian State University of
Informatics and Radioelectronics (BSUIR), Faculty of Computer Systems and Networks, Department
of Electronic Computing Facilities, 2022. The device firmware is in
[beanbo/E-book](https://github.com/beanbo/E-book).

The repository holds the project brief, explanatory note, title page, bill of materials,
assembly specification, review, drawings and schematics as PDF, Altium Designer and AutoCAD
sources, and draw.io diagrams. All documents are in Russian. There is nothing to build; open
them with Word/LibreOffice, a PDF viewer, draw.io, Altium Designer or AutoCAD.

Work history: April–June 2022, from the first files (2022-04-15) to the final version
(2022-06-08).
